# Conversión entre grados y radianes — PM4000

Aplicación interactiva para practicar conversiones entre grados y radianes.

## Funcionalidades
- Español por defecto y cambio a inglés.
- Modo grados → radianes.
- Modo radianes → grados.
- Respuestas exactas usando fracciones de π.
- Acepta fracciones equivalentes y muestra la forma simplificada.
- Representación animada del ángulo en SVG.
- Pista opcional con la fórmula de conversión.
- Diseño responsivo usando la identidad gráfica de PM4000.

## Archivos
- `index.html`: estructura de la aplicación.
- `styles.css`: identidad visual y diseño responsivo.
- `app.js`: lógica matemática, generación aleatoria, animación e idiomas.
