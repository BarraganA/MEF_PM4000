# Posición estándar y ángulos coterminales — PM4000

Aplicación interactiva para trabajar:

- posición estándar;
- sentido positivo y negativo de una rotación;
- ubicación del lado terminal;
- ángulos cuadrantales;
- ángulos mayores que una vuelta;
- ángulos coterminales;
- reducción de un ángulo a una vuelta;
- representación en grados y radianes.

## Modos

1. **Explorar**
2. **Posición estándar**
3. **Coterminales**
4. **Reducir a una vuelta**

La interfaz inicia en español y puede cambiarse a inglés.
