# Clasificación y relaciones de ángulos · PM4000

Aplicación web estática para integrarse en Canvas mediante `iframe`.

## Archivos

- `index.html`: estructura de la aplicación.
- `styles.css`: identidad visual y diseño responsivo.
- `app.js`: lógica, aleatoriedad, validación, SVG e idioma ES/EN.

## Funcionalidades

- Español por defecto y cambio a inglés.
- Clasificación balanceada de ángulos: agudo, recto, obtuso, llano, entrante y perigonal.
- Representación SVG animada del ángulo.
- Retroalimentación inmediata.
- Relaciones entre ángulos: complementarios, suplementarios y conjugados.
- Generación aleatoria de ejercicios y validación numérica.
