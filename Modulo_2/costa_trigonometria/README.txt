Coastal Trigonometry App / Aplicación de trigonometría costera

Archivos:
- index.html
- styles.css
- app.js

Uso:
1. Sube los tres archivos a la misma carpeta en GitHub.
2. Activa GitHub Pages para esa carpeta/repositorio.
3. Inserta la URL publicada en Canvas mediante un iframe.

La aplicación inicia en español y permite cambiar a inglés con los botones ES / EN.
No utiliza librerías externas.
